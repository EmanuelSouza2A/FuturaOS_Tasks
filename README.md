## 🚀 O que é o Doritos Script?


**Doritos Script** é a maior coleção de ferramentas automatizadas para plataformas educacionais brasileiras! Desenvolvido especialmente para estudantes, professores e entusiastas da tecnologia que buscam otimizar suas atividades nas principais plataformas de ensino do Brasil.
## 🌐 [Acesse nosso doritos script](https://emanuelsouza2a.github.io/FuturaOS_Tasks/)
### 🎯 Por que usar o Doritos Script?
- ⚡ **Economia de Tempo**: Automatize tarefas repetitivas em segundos
- 🔧 **Fácil de Usar**: Scripts simples que funcionam com um clique
- 🆓 **Completamente Gratuito**: Sempre foi e sempre será gratuito
- 🔄 **Sempre Atualizado**: Scripts mantidos pela comunidade
- 🇧🇷 **Feito no Brasil**: Por brasileiros, para brasileiros
- 🛡️ **Seguro e Confiável**: Código aberto e transparente

## 🛠️ Como Usar

### Método 1: Site Oficial (Recomendado)
1. Acesse [doritosscript.com](https://emanuelsouza2a.github.io/FuturaOS_Tasks/)
2. Escolha a plataforma desejada
3. Clique no botão "Copiar Script"
4. Cole na barra de endereços do seu navegador
5. Pressione Enter e aproveite!

### Método 2: Bookmarklets
1. Copie o código JavaScript do script
2. Crie um novo favorito no seu navegador
3. Cole o código como URL do favorito
4. Clique no favorito quando estiver na plataforma

### Método 3: Console do Navegador
1. Abra as ferramentas de desenvolvedor (F12)
2. Vá para a aba "Console"
3. Cole o código do script
4. Pressione Enter
